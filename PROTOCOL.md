# CCC Protocol

This is the reusable root protocol for Codex-Claude file-based co-op.

Copy or install `templates/coop/` into each target project. The target project's `coop/PROTOCOL.md` is the operational source of truth for that run.

For supervised runs, `docs/SUPERVISOR_V1.md` is the lifecycle contract and
`coop/.ccc/` is the local-only lifecycle SSOT. Markdown inboxes remain the
human collaboration surface; they are not a lease, scheduler, or proof that a
turn executed.

## Required Channels

- `coop/chat.md`: append-only informal channel.
- `coop/inbox_codex/`: tasks for Codex.
- `coop/inbox_claude/`: tasks/replies for Claude.
- `coop/reports/`: durable reports that are not addressed to one agent.
- `coop/operator/commands.md`: remote operator commands, especially via GitHub.
- `coop/RUN_STATE.md`: current run state.
- `coop/STOP.md`: if present, both agents write final summaries and stop.

## Verdict Format

Every official reply starts with one line:

```text
VERDICT: ok
```

Allowed verdicts:

- `ok`: task completed or no issue found.
- `issues_found`: task completed and actionable issues were found.
- `blocked`: task cannot proceed without external input or state change.

After the verdict, put key points first. Assume the other agent may have little context left.

## Agent Ownership

- Codex writes official replies for Claude under `coop/inbox_claude/`.
- Claude writes official replies for Codex under `coop/inbox_codex/`.
- Both may append to `coop/chat.md`.
- Both may write scratch files under `coop/scratch/`.
- Shared status should be split as `STATUS_codex.md` and `STATUS_claude.md` or generated by script.

## Wake discipline

At each manual or external wake:

1. Check `coop/STOP.md`.
2. Read the tail of `coop/chat.md`.
3. Check the agent's inbox.
4. Check operator commands.
5. Continue the active task or report idle status.
6. Apply adaptive quiet backoff when repeated wakeups find no work.
7. If supervised, let the supervisor record the wake and claim; an agent must
   not re-arm itself or claim work through prose.

Legacy human heartbeats may use 10, 30, then 90 minute quiet backoff. They do
not authorize model calls and must not run forever. A supervised `serve` call
has an explicit finite cycle budget, watch TTL, and wake budget.

If no deterministic wake mechanism is configured, say so plainly.

## GitHub Snapshot Discipline

Snapshots are for remote visibility. Commit only:

- `coop/*.md`
- `coop/inbox_*/*`
- `coop/reports/*`
- small ledgers and manifests under `coop/scratch/`

Do not commit:

- secrets
- API keys
- PDFs or copyrighted corpora
- huge generated artifacts
- local environment dumps

## Stop Behavior

If `coop/STOP.md` exists:

1. Stop starting new work.
2. Move a supervised run to `draining` and cancel only supervisor-owned work.
3. Write a final summary to `coop/inbox_<other_agent>/FINAL_SUMMARY.md`.
4. Append one line to `coop/chat.md`.
5. Do not continue polling or resume the old generation when STOP is removed.
